# 译林版高一必修一单词检测工具
牛津译林2019版 必修第一册 单词网页自测工具 ✅
👉 在线地址：https://你的用户名.github.io/yl-b1-vocab/

## 功能
1. 🎮 **单词消消乐模式**：卡片随机打乱，点击【英文单词 ↔ 中文释义】配对消除，计时计分
2. 📝 **默写检测模式**：英译汉 / 汉译英自测，判断对错、统计正确率、标记生词
3. 📖 单元切换：Unit1~Unit4独立选词
4. 📄 词库导出：原始单词表为 `wordlist.md`，可直接下载打印、二次编辑
5. 📢 网页朗读：Web Speech API 读单词发音
6. 📱 响应式：手机、电脑浏览器直接打开，无需安装

## 使用方法
1. 打开在线网页，选择单元
2. 切换模式：【消消乐游戏】 / 【单词默写检测】
3. 消消乐：点英文卡片，再点对应中文，匹配成功消除；错了卡片抖动提示
4. 默写模式：输入释义，自动判分，结束导出错题清单

## 本地运行
直接下载 `index.html`，双击用浏览器打开即可，不需要服务器。

## 修改词库
修改 `wordlist.md`，或者直接在html内的words数组增删单词；
格式：`{en:"xxx", phon:"xxx", pos:"xxx", cn:"xxx", unit:1}`
